Render published Router forms through a dynamic block or shortcode while inheriting the active WordPress theme.

== Installation ==

1. Upload and activate the plugin ZIP.
2. Generate a site token in Router under Forms > WordPress.
3. Paste the token under Settings > Router Forms.
4. Insert the Router Form block or use [router_form id="PUBLIC_ID"].

The token is stored server-side. Post content stores only the public form ID.
